Приложение разрабатывается на C++ с использованием Qt для графического интерфейса и libcurl для HTTP(S)-запросов. 

Пользователь открывает приложение на компьютере, добавляет адрес веб-ресурса и задает параметры проверки. После подтверждения разрешения система получает доступные страницы в заданной области и анализирует ответы сервера. Результаты планируется отображать в приложении и сохранять в защищенном локальном хранилище. Пользователь сможет вернуться к истории проверок, сравнить результаты и сформировать отчет
